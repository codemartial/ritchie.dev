The language, runtime model and technical foundations behind Ritchie.

  • RITE — Reliable Interaction with Typed Endpoints

    RITE is an architectural style and abstract execution model for distributed applications. It combines established reliability techniques into one typed application model in which state ownership, invariant boundaries, and interaction behaviour are specified together.

    Each component has an explicit contract, owns its state and invariants, and communicates through well-defined interaction modes that determine consistency and failure semantics. Every interaction has a stable identity, a finite budget, and a classifiable outcome. These rules make mutations safe to retry within a defined window, keep invariants within one owner, and make effects attributable to their causes.

    By placing these rules in the application model, RITE enables static compatibility checks and consistent runtime behaviour across component relationships. Its semantics do not depend on process layout, placement, replication, or storage mechanisms. Version 1.0 covers one datacenter or a cluster of well-connected datacenters. Multi-region interaction is outside its scope.
