First-class support for distributed concepts.

Ritchie has built-in archetypes for distributed system components like stateless services, transactional state, queryable state, and streams, each with interaction semantics defined by RITE. Choose the right archetype for each domain type to match the distributed architecture you need.

@T

Services

Stateless, networked application operations.

$T

Entities

Durable identity and transactional state.

%T

Projections

Read-only rows over committed state.

T~>

Streams

Continuous facts and subscriptions.

T!

Errors

Typed, recoverable domain outcomes.
